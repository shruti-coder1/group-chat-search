# AI Group Chat Search

An AI-powered search tool for a synthetic group chat. It supports semantic, attributed, and temporal queries and shows the matching message with surrounding conversation.

## Features

- Semantic search by meaning
- Search by participant
- Time-based search
- Hinglish and code-mixed chat messages
- Surrounding conversation context
- 4,010 synthetic messages
- 8 participants
- 6 months of chat data
- Browser-side semantic embeddings using Transformers.js
- 40 evaluation queries
